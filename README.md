# 学术写作风格、分词用语、逻辑推进与解释方法指南

## 1. 世界顶级学院核心写作逻辑
- **芝加哥大学（Cochrane & Williams）**：倒三角结构（首段直陈核心定量贡献，主结果前零冗余）；句间遵循 Old-to-New 信息流（句首锚定旧信息，句末重音推出新结论）；以经济主体或算子作主语、强动词作谓语；拒绝裸 `this`；按 Describe → Explain → Compare 顺序阐述方法，正面回答实证识别三问（右侧变异、误差项机制、正交条件）。
- **哈佛大学（Shapiro & Writing Center）**：为机器人写正文（Robot Test：符号线性先定义后使用、推理无跳跃、语言平实、数学严格）；导言作为与读者的精确契约；段末用 Turn Against & Turn Back 回应竞争解释并锁定成立边界。
- **MIT（21W.732）**：严格分离观察事实（Report）与机制推演（Interpret）；每段由中心句统摄单一问题；按内容→结构→风格三阶修改。

## 2. 分词与用语习惯
- **四类结构连接符**：`×` 表交互固定效应（`行业×年度`、`出口国×危机后`）；`—` 表双边或跨层关系（`银行—企业关系`、`实体—金融反馈`）；`→` 表传导时序（`生产→企业财务→贷款`）；`／` 表对偶边际或比值（`进入概率／退出概率`、`净外债权／GDP`）。
- **双音节强动词**：网络与矩阵用 `投射、门控、去重、折减、张成、消去、左乘`；金融与传导用 `穿透、侵蚀、折价、减记、核销、火售、抽走、转贷、重配`；计量识别用 `吸收、剥离、净出、残差化、事前冻结、当期联立`。
- **句法三铁律**：删去“先否定再解释”绕弯句式；先写清设计吸收了什么再直陈剩余正交识别条件；明确标定矩阵行列方向与分母口径。

## 3. 逻辑推进与解释方法
- **双轨六步推进**：问题与状态条件 → 制度摩擦或三层模型解耦（非线性均衡/一阶线性动态/二阶福利近似） → 变量构造或代数消元推导 → 识别正交条件或福利分解 → 分层定量结果与反事实对照 → 扩展模型与迁移边界。
- **机制与公式解释**：打通会计资产负债接口，先用纵向链/横向特例与 2–4 节点数字算例算透，再按“定位层级→锁定符号定义域→算子路径翻译→损益对译→补全消元与一阶条件→存在唯一性边界→原印疑点与教学一致式并列→独立脚本验证”八步拆解。
- **实证四维透视**：单位与对数精确换算、固定效应列空间与有效组内样本、两步法 FWL 条件与生成回归量、缺失值回填与历史假设。
